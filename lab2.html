Лабораторная работа № 2. Простой сайт на Django

Выполнила: Сафонова Арина, группа K3341.
Номер в журнале: 24.
Вариант: 6 — «Табло победителей автогонок».

Цель

Реализовать сайт средствами Django с моделью данных, пользовательскими интерфейсами и административной панелью.

Задание

Условия лабораторной работы.

При циклическом распределении шести вариантов номеру 24 соответствует вариант (24 - 1) % 6 + 1 = 6.

Необходимо хранить сведения об участниках автогонок, регистрировать пользователей и гонщиков, позволять пользователям изменять и удалять свои регистрации, оставлять комментарии с рейтингом, а администратору — указывать время заезда и результат. Для выбранной гонки требуется таблица всех заездов и результатов.

Средства реализации

Python 3.9, Django 3.2, Jinja2, PostgreSQL. Отчет оформлен средствами MkDocs.

Архитектура Django MVT соответствует разделению MVC: модели описывают данные, представления обрабатывают запросы, шаблоны формируют HTML. Обработчики основного приложения написаны функциями. Собственные страницы используют Jinja2, встроенная панель администратора — DjangoTemplates. Для оформления подключен локальный файл CSS.

Модель данных

Модель Содержимое
User Стандартная учетная запись Django
Race Название гонки, даты начала и окончания
Registration Гонка, пользователь, ФИО гонщика, команда, описание автомобиля, описание участника, опыт, класс, время заезда, результат
Comment Гонка, автор, даты заезда, текст, тип комментария, рейтинг

Регистрация связывает одного пользователя и одного гонщика с выбранной гонкой. Строка регистрации также хранит результат его заезда. Гонка и пользователь связаны с регистрациями и комментариями отношениями один-ко-многим.

Время заезда хранится в DurationField, результат — текстом. В комментарии сохраняются даты выбранной гонки на момент добавления. Тип комментария выбирается из трех значений: вопрос о сотрудничестве, вопрос о гонках, иное. Допустимый рейтинг — целое число от 1 до 10.

Реализованные интерфейсы

Адрес Назначение
/ Список гонок с поиском по названию и пагинацией по пять записей
/register/ Регистрация: имя пользователя, пароль и подтверждение пароля
/login/ Вход по имени пользователя и паролю
/logout/ Выход из учетной записи по кнопке
/races/<id>/ Таблица участников и результатов выбранной гонки, комментарии
/races/<id>/register/ Форма регистрации гонщика
/registrations/ Собственные регистрации пользователя
/registrations/<id>/edit/ Изменение данных гонщика в своей регистрации
/registrations/<id>/delete/ Подтверждение удаления своей регистрации
/races/<id>/comment/ Добавление текста, типа комментария и рейтинга
/registrations/<id>/result/ Ввод времени заезда и результата администратором на клиенте
/admin/ Стандартная панель Django для управления моделями

Список гонок, поиск и пагинация

Поле «Название гонки» фильтрует гонки по части названия без учета регистра. Поиск реализован через name__icontains. Кнопка «Сбросить» возвращает полный список.

Используется базовый Paginator: пять гонок на странице, ссылки «Назад» и «Далее», номер текущей страницы. Фильтрация выполняется до разбиения на страницы. Параметр q сохраняется в ссылках перехода. Если совпадений нет, выводится «Гонки не найдены».

Регистрация и вход

Для создания пользователя применяется UserCreationForm, для входа — AuthenticationForm. После регистрации выполняется вход. Пароли сохраняются стандартными средствами Django в виде хеша.

Регистрация гонщика

На странице выбранной гонки пользователь открывает форму с ФИО, командой, описаниями автомобиля и участника, опытом и классом. Гонка задается адресом страницы, владелец регистрации — текущим пользователем.

Раздел «Мои регистрации» показывает только собственные записи. Изменение позволяет исправить сведения о гонщике. Удаление выполняется после подтверждения формы. Время и результат не входят в пользовательскую форму.

Таблица гонки и комментарии

Таблица включает ФИО, команду, автомобиль, описание участника, опыт, класс, время и результат. Выводятся все регистрации именно выбранной гонки. До заполнения результата показано, что он не указан.

Под таблицей находятся комментарии: автор, тип, рейтинг, даты заезда и текст. Отправка комментария доступна после входа. Автор и даты записываются автоматически.

Администрирование

Администратор может указать время и результат в форме регистрации через Django-admin. В клиентском интерфейсе ему дополнительно доступна ссылка «Указать результат» в таблице гонки. Она открывает форму времени в формате ЧЧ:ММ:СС и текстового результата.

Признаки is_staff / is_superuser проверяются в шаблоне и обработчике. Изменение или удаление регистрации обычным пользователем выполняется только для записи с user=request.user. Формы используют штатную CSRF-защиту.

Проверка

Проверены регистрация и вход пользователя, просмотр гонок, создание, изменение и удаление собственной регистрации, недоступность чужих регистраций, добавление комментариев, границы рейтинга 1–10, ввод результата через клиент и Django-admin. Проверено, что таблица содержит записи только выбранной гонки. Миграции и сборка MkDocs выполняются без ошибок.

Дополнительно реализованы собственные CSS-стили, базовая пагинация, поиск и фильтрация гонок по названию, разграничение прав администратора и пользователя в клиентском интерфейсе. Проверены фильтрация без учета регистра, пустая выдача и сохранение поискового запроса при переходе между страницами.

Вывод

Реализованы функции варианта 6, модель PostgreSQL, шаблоны Jinja2, разграничение действий пользователя и администратора. Подготовлены практики 2.1–2.3. Инструкция запуска находится в README проекта.
